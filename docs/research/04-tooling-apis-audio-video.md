# 04 - Tooling, APIs, audio and video (researched Oct 2026)

## Keyword and trend research tools
- **eRank** has the most useful free plan (about 200 keyword lookups/day, listing audits, trends); **EverBee** has a limited free tier (revenue estimates are paid); **Alura** and **Marmalead** are paid-first (Marmalead 14-day trial) ([Craftybase](https://craftybase.com/blog/best-etsy-seo-tools), [SellerToolsHQ](https://sellertoolshq.com/tools/compare/erank-vs-everbee/)). Free sources: Etsy/Pinterest search autocomplete and result counts, Pinterest Trends, Google Trends. MoneyHub does **not** scrape Etsy or Pinterest (terms of service); it prints the phrases to check by hand and can expand seeds with an LLM.

## Platform APIs (can listings be created by code?)
| Platform | Product creation by API | Notes |
|---|---|---|
| Etsy Open API v3 | Yes: create draft listing, upload images/files | Personal App for your own shop; Commercial Access needs manual review; file upload optional for digital drafts since 29 Jan 2026 ([etsy/open-api](https://github.com/etsy/open-api/discussions/1524), [VorpLabs](https://vorplabs.com/agent-tools/etsy-api)). **Could not be verified here:** etsy.com is blocked from this sandbox, so the field list was not checked. |
| Pinterest API v5 | Create pins (images and video) | Trial access: pins visible only to you, 1,000 calls/day; Standard needs a demo video review; 100 writes/min/user; developer rules expect a human to review each action ([Pinterest docs](https://developers.pinterest.com/docs/key-concepts/access-tiers/), [upload-post](https://www.upload-post.com/pinterest-api/)) |
| Shopify Admin API | Yes (productCreate) | Digital Downloads app needed for files ([Shopify](https://shopify.dev/docs/api/admin-graphql/latest/mutations/productCreate)) |
| Whop | Yes (create product) | [Whop docs](https://docs.whop.com/api-reference/products/create-product) |
| Lemon Squeezy | Products created in dashboard; API is mainly read/checkout | [docs](https://docs.lemonsqueezy.com/guides/getting-started) - verify before relying on it |
| Gumroad / Payhip / Ko-fi | No public create-product API | Manual upload |

**Decision:** keep manual upload as the supported path (you review everything); the guides and upload packages make it fast. A draft-only Etsy publisher is the first API integration worth building once someone can test it against a real shop.

## Document engines
- **Typst** is far faster than WeasyPrint (reported 106 ms vs 335 ms per page; 500 pages in 157 ms vs 8.7 s) and has calendar packages, but WeasyPrint's HTML/CSS pagination suits our templates ([speedata benchmark](https://github.com/speedata/typesetting-benchmark), [Typst blog](https://typst.app/blog/2025/automated-generation/)). Future option for very long planners.

## Text to speech (voice-over)
- **Kokoro-82M**: Apache-2.0, ~350 MB, 54 voices, runs on CPU; `kokoro-onnx` avoids PyTorch ([Kompozy](https://kompozy.io/reviews/kokoro-tts), [VisionStory](https://www.visionstory.ai/open-source/kokoro-tts)). Chosen engine for `--voice`.
- **Piper**: the maintained repo moved to GPL-3.0 and bundles espeak-ng (GPL) - avoid embedding it ([cekura](https://www.cekura.ai/discover/piper-tts)). **macOS `say`** is available offline on a Mac (system voices; check Apple's terms before commercial use of the audio).

## Music
- **Generated by MoneyHub:** a small synth (chords, bass, drums, arpeggio, SFX) written in Python/NumPy, so there is no licence question; this is the default.
- **AI music models:** MusicGen weights are CC-BY-NC (non-commercial, do not use); Stable Audio models use the Stability Community Licence (free commercial use under USD 1M revenue); ACE-Step 1.5 is MIT and described as commercial-friendly ([Boppy](https://boppy.me/blog/best-open-source-ai-music-models), [ACE-Step](https://github.com/ace-step/ACE-Step-1.5)). Optional later; needs a GPU or patience on an M-series Mac.
- **Stock music:** Pixabay Music (Pixabay Content License: commercial use, no attribution, but no standalone resale) and YouTube Audio Library (some tracks need attribution) ([Swarmify](https://swarmify.com/blog/free-music-for-your-videos-the-importance-and-where-to-find/), [vidIQ](https://vidiq.com/blog/post/royalty-free-music-youtube-audio-library/)). MoneyHub accepts your own file via `--music-file`; keep the licence proof.
- **Etsy removes audio from listing videos**, so music is for Pinterest/TikTok/Reels versions only.

## Video frameworks
- **HyperFrames** (HeyGen, Apache-2.0): HTML/CSS + seekable animations to deterministic MP4 via headless Chrome and FFmpEG; ships agent skills ([GitHub](https://github.com/heygen-com/hyperframes)). The `/brag` skill uses it. MoneyHub's built-in Pillow engine, Remotion and Manim cover the same need; a HyperFrames engine can be added later.
- **Remotion** licence: free up to 3 people; see `docs/licenses.md`.

## Mockups
- Open-source frame/room mockup scripts exist ([frameMockupGen](https://github.com/beephole/frameMockupGen)), and BlenderKit has procedural wall-art scenes; MoneyHub draws its own gallery wall with Pillow (no third-party assets).
