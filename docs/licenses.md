# Licences: what MoneyHub uses, and what I checked

This is a practical summary, not legal advice. "Checked" means I read the licence text or the project's own licence page during development (Oct 2026); everything else comes from package metadata or general knowledge, so re-verify before relying on it commercially.

## The open-source planner generators I looked at
| Project | Licence | Checked | What it means for MoneyHub |
|---|---|---|---|
| [mohanrex/digital-planner-generator](https://github.com/mohanrex/digital-planner-generator) (React/TypeScript, pdf-lib) | **MIT** (copyright 2025) | LICENSE file + README | Permissive: code could be reused with the copyright and licence notice kept. |
| [georgiastuart/planner-generator-python](https://github.com/georgiastuart/planner-generator-python) (Python, Jinja2, Playwright) | **GNU GPL v3** | LICENSE file | Strong copyleft: copying its code into MoneyHub would require MoneyHub to be GPL-3 if you ever distribute it. |

**Decision:** no code, templates or assets from either project are in MoneyHub. The hyperlinked tablet planner was written from scratch (WeasyPrint internal links and bookmarks); only the general idea (linked pages for GoodNotes) is shared, and ideas are not protected by copyright. Keep it that way: if you want something from the GPL project, re-implement it instead of copying. Using either project as a separate tool to make your own PDFs is fine (a GPL licence does not normally cover files a program outputs unless the output contains parts of the program), but do not redistribute their code.

## Content that ends up inside what you sell
- **Fonts:** Google Fonts under the SIL Open Font License. Allowed inside products you sell (embedded in PDFs, rendered in images). Do not include the font files themselves in a download. The `editable/fonts/` folder is for your own editing only.
- **Artwork:** procedural SVG generated by MoneyHub, so no third-party licence applies.
- **AI-generated backgrounds (optional):** governed by each provider's terms (FLUX.1-schnell is Apache-2.0; other models and API terms differ). Read them before selling the output.
- **Text:** written by the AI provider you choose; follow Etsy's AI-disclosure rules (the generated listing description includes the line).
